# TYPICAL COOK UA — версия 3.0

Готовый сайт на украинском языке. Использует 4 изображения в фирменном комикс-стиле.

- `index.html` — версия для сайта / GitHub Pages. При публикации обязательно сохраняйте папку `assets`.
- `assets/logo-round.webp` — круглый логотип.
- `assets/fire-kitchen.webp`, `assets/tech-cards.webp`, `assets/kitchen-life.webp` — редакционные изображения.
- `assets/original-logo.webp` — оригинал логотипа пользователя для архива.

Для открытия одним файлом с Android используйте `typical-cook-ua-v3-mobile.html` из отдельной ссылки: в этом варианте изображения встроены и не зависят от путей к папкам.

Тексты материалов демонстрационные. Журнал — концепция, PDF еще не прикреплен. TikTok ссылается на поиск проекта, поскольку подтвержденная прямая ссылка на аккаунт не предоставлена.
